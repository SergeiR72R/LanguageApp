# Картинки для слов через Google Flow (с помощью Claude в Chrome)

## Что подготовить
1. Откройте в Chrome **Google Flow** (https://labs.google/flow) и войдите в Google-аккаунт.
2. Скачайте нужный CSV из папки `tools/word-images/`:
   - `b1-core.csv`, `b2-core.csv`, `c1-core.csv` — по 200 основных слов каждого уровня. **Начните с них.**
   - `*-bank.csv` — большой словарь («слова дня», 800–1 300 на уровень). Это много кредитов Flow — делайте потом и частями.
3. Откройте CSV в Google Таблицах (или прямо во вкладке браузера), чтобы Claude в Chrome его видел.
4. Создайте на компьютере папку `deutsch-word-images` — туда будут скачиваться картинки.

## Промпт для Claude в Chrome (скопируйте целиком)

```
Задача: сгенерировать в Google Flow иллюстрации для карточек немецких слов и скачать их с правильными именами файлов.

Исходные данные — таблица во вкладке с CSV (колонки: file_name, german, russian, part_of_speech, example_sentence). Работай по строкам сверху вниз. Начни со строк 2–21 (первые 20 слов), потом спроси меня, продолжать ли.

Для каждой строки:
1. Придумай по-английски короткое описание сцены (1–2 предложения), которое однозначно показывает значение слова из колонок german/russian. Используй example_sentence как подсказку контекста.
   - Существительное-предмет: один предмет крупно по центру.
   - Глагол: человек, выполняющий действие.
   - Прилагательное/наречие: сцена, где это свойство очевидно (например, «laut» — человек закрывает уши от громкой музыки).
   - Абстрактное слово или выражение: простая символическая сцена с 1–2 персонажами, понятная без текста.
   - Обстановка по возможности немецкая (немецкий город, квартира, офис, природа).
2. В Flow выбери режим создания ИЗОБРАЖЕНИЯ (не видео), соотношение сторон 1:1 (квадрат), 1 вариант (если можно выбрать количество).
3. Вставь промпт в таком виде:
   "<описание сцены>. Style: cheerful flat vector illustration with soft shading, rounded shapes, warm pastel colors, plain light background, single clear focal subject, centered composition, friendly characters, high detail but uncluttered. Absolutely no text, no letters, no numbers, no captions, no watermarks."
4. Дождись результата. Если на картинке появился текст/буквы или смысл неочевиден — сгенерируй ещё раз с уточнённым описанием (не больше 2 попыток на слово).
5. Скачай изображение в папку deutsch-word-images и назови файл ТОЧНО как в колонке file_name (например lebenslauf.png). Если Flow скачивает с другим именем — переименуй.
6. Отметь в таблице (новая колонка status) «готово» или «пропущено» с причиной.

Правила:
- Одна картинка = одно слово. Никакого текста на изображениях.
- Если кончились кредиты Flow или появилась ошибка/капча — остановись и сообщи мне, на какой строке остановился.
- После каждых 20 слов присылай короткий отчёт: сколько готово, какие пропущены.
```

## Как добавить картинки в приложение
Пришлите мне архив папки `deutsch-word-images` (или положите файлы в `src/assets/words/` репозитория).
Приложение само подхватит картинку по имени файла: `lebenslauf.png` → слово «Lebenslauf».
Подходят форматы `.png`, `.jpg`, `.webp`. Желательно до ~150 КБ на картинку (я могу сжать их при добавлении).

Список можно пересоздать после изменений словаря командой: `npx vite-node tools/export-words.ts`.
