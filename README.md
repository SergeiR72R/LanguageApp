# Deutsch B1–C1 Trainer

Персональный тренажёр немецкого языка от B1 до C1: слова, грамматика, аудирование, письмо и говорение.
Работает в браузере (компьютер или телефон), прогресс хранится локально.

## Что внутри

- **Тест уровня** — 52 вопроса A2–C1 (грамматика, лексика, чтение, аудирование) с ранней остановкой; по желанию ИИ оценивает
  короткий текст о себе. По результату выбирается стартовый юнит.
- **Объём:** ~8 000 слов (B1 ≈ 2 360, B2 ≈ 3 710, C1 ≈ 1 920), 1 600 грамматических упражнений, 100 текстов для чтения
  и 150 для аудирования в формате Goethe, 9 пробных экзаменов Goethe-Zertifikat (по 3 на B1, B2, C1),
  473 глагола с управлением (предлог + падеж) в тренажёре «Глаголы».
- **Последовательный курс** — 50 юнитов (B1 ×20, B2 ×20, C1 ×10). Каждый юнит — 7 шагов (основные ниже, плюс «Чтение»):
  1. 📚 **Слова** — 20 слов с артиклями, формами, примерами и озвучкой; проверка и тренировка артиклей.
  2. 🧩 **Грамматика** — объяснение на русском, таблицы, примеры, 12 упражнений (выбор, пропуск, порядок слов,
     трансформация). Зачёт от 75 %. ИИ может сгенерировать новые упражнения.
  3. 🎧 **Аудирование** — монолог или диалог (два голоса), вопросы, транскрипт, диктант; ИИ генерирует новые тексты.
  4. ✍️ **Письмо** — задание уровня экзамена; ИИ проверяет текст: оценка по критериям, все ошибки с объяснением на русском,
     исправленная и улучшенная версия.
  5. 🗣️ **Говорение** — чтение вслух с проверкой произношения + ролевой диалог с ИИ голосом, разбор ошибок каждой реплики
     и итоговая оценка.
  6. 🏁 **Тест юнита** — от 70 % открывается следующий юнит.
- **Слова дня** — ежедневная порция (10–30) из большого словаря курса.
- **Пробные экзамены** — Lesen, Hören (с ограничением прослушиваний), Schreiben и Sprechen (оценка ИИ), таймер, 60 баллов для сдачи.
- **Мотивация** — XP, уровни, дневная цель, 24 достижения, дуэль и рейтинг между профилями, конфетти и звуки.
- **Ежедневный план** — повторение → следующие шаги текущего юнита (по бюджету 20/40/60 мин) → еженедельная контрольная
  на закрепление → работа над ошибками → разговорная практика.
- **Интервальное повторение (SM-2)** — слова (узнавание → перевод → на слух), грамматические задания и собственные ошибки.
- **Тетрадь ошибок** — ошибки из письма и речи с категориями (Kasus, Wortstellung, Adjektivendung…), статистика слабых мест
  и упражнения от ИИ именно на них.
- **Несколько учеников** — профили на одном устройстве (например, вы и супруга): у каждого свой тест уровня, курс, повторение и ошибки; переключение в меню слева или на странице «Сегодня».
- **Прогресс** — серия дней, тепловая карта активности, прогноз повторений, результаты по юнитам. Экспорт/импорт данных.

## Бесплатные API

| Функция | По умолчанию | Альтернативы |
|---|---|---|
| Языковая модель (проверка, диалог, анализ) | **Groq** `openai/gpt-oss-120b` | Gemini (`gemini-2.5-flash`), OpenRouter (`:free`-модели), локальный Ollama |
| Распознавание речи | **Groq Whisper** `whisper-large-v3-turbo` | Web Speech API браузера (Chrome/Edge/Safari) |
| Озвучка | Голоса браузера (Edge «Natural», Google Deutsch) | **Gemini TTS** (нейроголоса, два голоса для диалогов) |

Достаточно одного бесплатного ключа Groq: <https://console.groq.com/keys> → «Настройки» → вставить ключ → «Проверить
подключение». Ключи хранятся только в вашем браузере и отправляются напрямую провайдеру. Названия моделей можно менять
в настройках (кнопка «Загрузить список моделей»), если провайдер обновит линейку.

Без ключа работают курс, упражнения, повторение, озвучка и чтение вслух через распознавание браузера; письмо и речь
засчитываются по самопроверке.

## Синхронизация между устройствами

Профили и прогресс синхронизируются через функцию Netlify (`netlify/functions/sync.mts`) и хранилище Netlify Blobs.
1. Netlify: сайт подключён к GitHub (ветка `main` — основной адрес, ветка `live` — бесплатная публикация
   на `live--<сайт>.netlify.app`), сборка берётся из `netlify.toml`. Копия на GitHub Pages обращается к той же функции
   (CORS разрешён в `sync.mts`).
2. Netlify → Site configuration → Environment variables: `SYNC_PASSWORD` = общий пароль семьи → передеплой.
3. В приложении: «Настройки» → «Синхронизация» (или на стартовом экране) → ввести пароль на каждом устройстве.

Данные с разных устройств объединяются (`src/lib/merge.ts`): шаги, карточки, слова, ошибки и активность не теряются.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты логики и проверка корректности учебного контента
npm run build      # статическая сборка в dist/
```

Для телефона удобно опубликовать на GitHub Pages: в настройках репозитория *Pages → Source: GitHub Actions*,
workflow `.github/workflows/deploy.yml` собирает и публикует сайт при пуше в `main` или `live`. Микрофон работает только по HTTPS
(или на localhost).

## Структура

```
src/content/          учебный контент: types.ts (схема), b1/ b2/ c1/ (юниты), placement.ts (тест уровня)
src/lib/              логика: srs.ts, daily.ts (план), placement.ts, grading.ts, store.ts (состояние)
src/lib/ai/           API: llm.ts, stt.ts (Whisper / браузер), tts.ts (браузер / Gemini), prompts.ts
src/pages/            экраны; src/pages/unit/ — шаги юнита
src/components/       упражнения, диалог, чтение вслух, озвучка
```

Добавить юнит: создать `src/content/<уровень>/uNN.ts` по схеме `Unit` — он подхватится автоматически,
`npm test` проверит формат.
